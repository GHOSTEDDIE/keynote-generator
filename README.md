# 有点东西 · 发布会文案生成器

纯前端 React 小工具：58 个原创句式，产品名自定义，四种口吻和自由随机，换整句、只换数字、复制，最近三句历史。数字和文案均为娱乐虚构。新增汽车、手机、中折叠、纸巾盒等，共 11 个物品快捷选项；按物品匹配豪车对标、镜头、铰链、车规级和行业首发句式。

## 启动

```sh
npm install
npm run dev
```

打开终端显示的本地地址。`npm test` 运行生成逻辑回归；`npm run build` 生成 dist；`npm run preview` 预览构建产物。无需密钥、数据库或服务端。

修改产品和口吻后点“再来一句大的”；“只换数字”保持当前文案的产品和句式。无随机数字的文案会禁用“只换数字”，并显示原因。空白产品名默认为杯子。复制需要浏览器允许剪贴板访问，使用 localhost 或 HTTPS；失败时可手动选中文案复制。历史只在当前页面保留，刷新即清空。

## 静态托管

GitHub Pages 地址：https://ghosteddie.github.io/keynote-generator/

仓库 Settings → Pages 的 Source 选择 GitHub Actions。推送到 main 后会自动安装依赖、运行测试、构建并发布。构建资源使用相对路径，也可以把 dist 的内容部署到其他静态托管服务。

## 修改句库

`src/generator.js` 集中维护句式、数字范围和产品替换；`src/main.jsx` 负责页面和交互；`src/style.css` 负责响应式布局。生成时排除上一句模板。
